g_health_issues(patient_ref bigint, episode_ref float, snomed_ref bigint, snomed_descr varchar(255), ou_med_ref varchar(255), start_date datetime, end_date datetime, end_motive float, load_date datetime)  # Patient diagnoses and health conditions. Use this for any question about diseases, conditions, or diagnoses. Column snomed_descr contains the condition name in Spanish. snomed_ref is the numeric SNOMED code — use it for reliable filtering when known. Always SELECT and GROUP BY snomed_descr to include condition names in results. ou_med_ref is the medical unit that RECORDED the diagnosis — this is NOT necessarily the unit that treats the patient.
