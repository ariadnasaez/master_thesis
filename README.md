# 🏥 DataNex Clinical Database Agent

A natural-language interface to a clinical MySQL database, built with the **Model Context Protocol (MCP)**. Users can ask medical questions in plain Spanish or English and receive SQL-backed answers generated by a local LLM.

## Overview

This project connects a local LLM ([Qwen 3.5:9B](https://ollama.com/library/qwen3.5) via [Ollama](https://ollama.com)) to a MySQL database containing de-identified clinical data from ~300 patients. The system uses MCP to expose database tools to the LLM, which autonomously writes and executes SQL queries to answer user questions.

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   User /    │────▶│   Client    │────▶│  MCP Server │────▶│   MySQL     │
│  Gradio UI  │◀────│  (Ollama)   │◀────│  (FastMCP)  │◀────│  Database   │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
```

### How it works

1. The **MCP server** (`server.py`) connects to MySQL and exposes two capabilities:
   - A **schema resource** — the full database schema with table descriptions, fetched once at startup
   - An **execute_query tool** — executes read-only SQL (SELECT/WITH) and returns JSON results

2. The **client** (`client.py` or `app.py`) orchestrates the conversation:
   - Fetches the schema and builds a detailed system prompt with domain-specific rules
   - Sends user questions to the LLM along with the schema context
   - The LLM calls `execute_query` via tool-calling (lookup queries first, then the main query)
   - Results are returned to the LLM, which formulates a natural-language answer

3. A **self-healing mechanism** automatically retries queries with fuzzy matching (LIKE) when exact text matches return empty results.

## Prerequisites

- **Python 3.11+**
- **MySQL** running locally with the `tfm_datanex` database
- **Ollama** installed with the `qwen3.5:9b` model pulled:
  ```bash
  ollama pull qwen3.5:9b
  ```

## Installation

```bash
# Clone the repository
git clone https://github.com/ariadnasaez/master_thesis.git
cd mcp_mysql

# Create and activate a virtual environment
python -m venv venv
source venv/bin/activate  # macOS/Linux

# Install dependencies
pip install -r requirements.txt
```

## Usage

### Web UI (recommended)

```bash
python app.py
```

Opens a Gradio chat interface at `http://127.0.0.1:7860` (and a public `*.gradio.live` link). Type questions in the chat box or click example prompts.

### Terminal

```bash
python client.py
```

Interactive terminal loop — type questions and see SQL queries + answers printed inline. Type `exit` to quit.

## Example Questions

| Question | What it does |
|---|---|
| ¿Cuántos ingresos por ictus isquémico hubo en 2024? | Counts hospitalizations by ICD code prefix I63% |
| ¿Qué anticoagulantes se administraron a pacientes con fibrilación auricular? | Joins administrations with diagnostics (I48%) |
| ¿Cuál es el valor medio de HbA1c en diabéticos tipo 2? | Lab lookup + unit conversion (IFCC→NGSP) |
| ¿Qué microorganismos se aislaron en hemocultivos positivos? | Filters g_micro by sample type and positive flag |
| ¿Cuál fue la primera troponina tras un cateterismo cardíaco? | CTE + ROW_NUMBER pattern for first lab after procedure |

## Database

The system works with the `tfm_datanex` MySQL database containing 33 tables across these domains:

| Domain | Key Tables |
|---|---|
| Demographics | `g_demographics`, `g_exitus` |
| Episodes & Movements | `g_episodes`, `g_movements`, `g_encounters` |
| Diagnoses | `g_diagnostics` (ICD), `g_health_issues` (SNOMED) |
| Lab & Microbiology | `g_labs`, `g_micro`, `g_antibiograms` |
| Medications | `g_administrations`, `g_prescriptions` |
| Procedures & Surgery | `g_procedures`, `g_surgery` |
| Severity | `g_diagnostic_related_groups` |

## Configuration

Database connection is configured in `server.py`:

```python
db_config = {
    "host": "127.0.0.1",
    "user": "root",
    "password": "",
    "database": "tfm_datanex",
    "port": 3306
}
```

To change the LLM model, update the `model` parameter in `client.py` and `app.py`:

```python
ollama.chat(model="qwen3.5:9b", ...)
```

## Technical Details

- **MCP Framework**: [FastMCP](https://gofastmcp.com) for the server, `mcp` Python SDK for the client
- **LLM**: Qwen 3.5:9B running locally via Ollama (no API keys or cloud services needed)
- **Tool-calling loop**: Up to 10 iterations with malformed-call recovery and a final-answer fallback
- **SQL safety**: Only SELECT and WITH queries are allowed; all other statements are rejected
- **Self-healing**: Empty results trigger automatic LIKE-based fuzzy matching on text columns
- **Web UI**: Gradio 6 ChatInterface with example prompts and SQL query display
